# Step 8 — Open the site and add an AI key

Open your domain in a browser. Create an account.

Go to **Settings**. Add an API key for chat:

- OpenRouter, or
- Groq, or
- Ollama, or
- an OpenAI-compatible key

You can also set your timezone.

The app is now running. Stop here if you only want notes, tasks, and chat.

To add Agent Workspace, go to [Step 9](/docs/selfhost/ubuntu-nginx-cloud/steps/09-run-workspace).
