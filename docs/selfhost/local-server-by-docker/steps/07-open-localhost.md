# Step 7 — Open http://localhost:2000

Open this address in your browser:

[http://localhost:2000](http://localhost:2000)

That is the full app. The website and `/api` share this port.

Do **not** use `http://localhost:3000` for this Docker path. Port 3000 is only for local website work without Docker.
