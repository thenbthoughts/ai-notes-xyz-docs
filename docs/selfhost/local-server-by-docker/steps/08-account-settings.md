# Step 8 — Create an account and add an AI key

Create an account on the site.

Go to **Settings**. Add an API key for chat:

- OpenRouter, or
- Groq, or
- Ollama, or
- an OpenAI-compatible key

You can also set your timezone.

The app is now running. Stop here if you only want notes, tasks, and chat.

To add Agent Workspace, go to [Step 9](/docs/selfhost/local-server-by-docker/steps/09-clone-workspace).
