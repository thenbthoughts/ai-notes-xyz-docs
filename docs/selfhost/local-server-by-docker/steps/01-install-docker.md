# Step 1 — Install Docker Desktop

Install [Docker Desktop](https://www.docker.com/products/docker-desktop/) and start it.

Docker is a tool that runs the app in a box. You need it running before the next steps.

On Windows, open Docker Desktop and wait until it says it is running.
